## Старый желаемый результат (v1)

Минимальный контур агента для разработки 1С 8 с **управляемыми и обычными
формами**; оценка адаптеров с опорой на Cursor; среди 19 входов выбрать
что взять / адаптировать / исключить.

## Новый желаемый результат (v2)

Тот же минимальный контур и эффективность контекста, но:

- обычные формы **не обязательны** (достаточно метаданных и управляемых);
- хост агента **не обязан быть Cursor**;
- состав: Unica, code-index-mcp / `bsl-indexer`, mcp-onec-test-runner,
  Answer42, Vanessa Automation и тонкий фасад;
- rlm-tools-bsl и skills Cursor/Claude **не входят** в контур;
- контур не для всех репозиториев пользователя (не каждый проект — 1С);
- в одном 1С-проекте допустимы несколько информационных баз (обмен);
- внедрять рано: сначала проверить интерфейсы и стыковку пяти компонентов.

Answer42 и Vanessa не входили во входные 19 URL снимка v1. На шаге
REASSESS они ещё не добавлялись в активный `request.repositories` /
INVENTORY. Позднее активный вход расширен: r20 и r21 со статусом
«ещё не исследован» — см. раздел ниже. Снимок v1 не менялся.

## Причина

Явное уточнение пользователя после обзора: Cursor и обычные формы
не принципиальны; нравится набор r01+r15+r09+Vanessa+Answer42 с обвязкой.

## Принятые решения

- Не писать с нуля индекс/справку/сборку/UI-движок.
- Узкая внешняя поверхность — фасадом, не сырым `tools/list` пяти MCP.
- Сначала адаптер фасада, потом точечный патч продукта.
- Определение 1С-проекта: по умолчанию существующие признаки и структура
  выгрузки; отдельный манифест — опциональная явная конфигурация
  (несколько sources/targets), не обязательный новый файл для любого 1С-проекта.
- Состав контура выбран; стыковка не исследована; «можно внедрять» — нет.

## Отклонённые гипотезы

- Fallback edit через cursor-1c-skills (`r12`), если Unica не в Cursor.
- Отдельный запуск `evaluations/ordinary-forms/`.
- Эксперименты V1–V3 (Unica в Cursor, ordinary/`Form.bin`) как приоритет.
- Обязательный `.1c-agent.yaml` как единственный способ узнать 1С-проект.
- Поднимать пять MCP глобально на машину.
