# r05 — https://github.com/Pr-Mex/UItoolsFor1C

Статус: обзор выполнен. Глубина: overview.

## Назначение и возможная роль

Набор Windows-утилит/DLL для Vanessa-Automation: стрелки, рамки, клики,
эмуляция клавиатуры. Часть шагов явно «платформа 8.3.11 и ниже». Роль:
**узкий спецслучай UI-видео/подсветки**, не проверка изменений агентом.

## Что изучено

Commit `3a3cf3c3f9541fad246e696f6ac6da83fd88ce8b`. README, дерево
(FrameShow, KeyboardType, MouseClick*, MouseMove, Strelka, Pramougolnik,
LICENSE.txt). Исходники Delphi/каталоги не разбирались построчно.

## Заявления и подтверждения

- **c05-vanessa-video** DOCUMENTATION. Инструменты для автоинструкций
  Vanessa, копируются в `VideoTools`.
- **c05-old-platform** DOCUMENTATION. FrameShow/MouseMove — 8.3.11 и ниже.
- **c05-not-agent-api** INFERENCE. Нет MCP/CLI для агента; это addon к
  Vanessa. Обычные формы напрямую не заявлены (работа с «активным контролом
  окна» может затрагивать любой Win32 UI, но это не доказательство модели
  обычной формы).

## Оценка относительно цели

C8 не закрывает: нет целевого отчёта агенту. Для ежедневного контура не
нужен. Контрпример: если пользователь уже пишет Vanessa-видеоинструкции
на старой платформе — оставить как локальный addon, не в tool surface.

Предварительное решение: **исключить из минимального контура**; спецслучай
Vanessa-видео.

## Резюме для пользователя

Полезен для: подсветка UI в Vanessa на старых платформах. Что не решает:
исследование, правка, сборка, компактный feedback. Решение: не включать.
