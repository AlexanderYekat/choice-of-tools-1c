# r06 — https://github.com/bia-technologies/rat

Статус: обзор выполнен. Глубина: overview.

## Назначение и возможная роль

Расширение 1С «Remote API for Testing»: REST для данных и регламентных
заданий плюс шаги Vanessa для чужой базы. Роль: **in-base runtime access**
для C8 (данные/RPC), не UI обычных форм и не правка исходников.

## Заявления и подтверждения

- **c06-rest-extension** DOCUMENTATION. REST для манипуляции данными и
  регламентными заданиями; шаги Vanessa.
- **c06-needs-ib** INFERENCE. Требует установить расширение в ИБ.
- **c06-forms** UNKNOWN. README не разделяет управляемые/обычные формы;
  API данных форм не доказывает.

## Оценка относительно цели

Дополняет feedback loop, если нужна проверка *данных* в работающей базе
без UI. Дублирует частично r08 (бизнес-данные), но r06 ближе к тестам.
Не заменяет YaXUnit (r09) и не заменяет Vanessa UI. Стоимость: расширение
в каждой рабочей базе.

Предварительное решение: **спецслучай runtime-данных / межбазовых тестов**;
не в минимальный ежедневный набор, пока не выбран сценарий «проверить
проводки через REST».

## Резюме для пользователя

Полезен для: HTTP-доступ к данным ИБ и Vanessa-шаги. Что не решает:
исходники, обычные формы как UI, компактный агентский facade без
расширения. Решение: отложить.
