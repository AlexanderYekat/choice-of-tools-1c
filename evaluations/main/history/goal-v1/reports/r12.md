# r12 — https://github.com/Desko77/cursor-1c-skills

Статус: обзор выполнен. Глубина: overview.

## Назначение и возможная роль

Набор Cursor skills/rules/commands + скрипты compile/decompile XML↔JSON
для метаданных, управляемых форм, ролей, СКД, EPF, выгрузки/загрузки ИБ,
Vanessa-шаги. Роль: **edit-toolkit и progressive disclosure инструкций**
(C5, частично C6/C7/C8), плюс образец router-скила. Это не индекс explore.

## Что изучено

Commit `8e9faca5bf516215c2a67a040c09288e2a31c16a`. README, listing
`skills/` (100+ каталогов, включая `1c77-dev` и не-1С скилы),

построчно.

## Заявления и подтверждения

- **c12-managed-forms** SOURCE. `1c-form-decompile` явно: «управляемой
  формы», `Form.xml` конфигуратора, DSL InputField/UsualGroup. Не
  Ordinary / Form.bin.
- **c12-ordinary-rule-only** SOURCE. `rules/1c-ordinary-forms.mdc`
  (`alwaysApply: false`) — текстовое правило про `ЭлементыФормы` и
  порядок видимости. Компилятора/редактора обычных форм 8.x нет.
- **c12-router** SOURCE. `1c-config-router` — таблица маршрутизации по
  скилам (progressive disclosure инструкций, не скрытие MCP).
- **c12-wide-catalog** SOURCE. Каталог скилов очень широкий, включая
  1С 7.7 и общие утилиты. Если агент видит все скилы сразу — удар по C10.
  В Cursor скилы обычно подгружаются по description; это не доказано
  замером.
- **c12-db-loop** DOCUMENTATION (router). Скилы `1c-db-dump/load/update/run`
  закрывают кусок C7 скриптами, без MCP-отчёта как у r09.
- **c12-vs-unica** INFERENCE. Пересекается с r01 по edit форм/метаданных.
  Unica даёт типизированный MCP facade; r12 — файловые скрипты + скилы
  под Cursor. Для Cursor r12 ближе по хосту; как ядро edit Unica сильнее
  контрактом, если MCP заведётся.

## Оценка относительно цели

Сильный кандидат на **адаптацию**: взять не весь каталог, а router +
meta/form/db скрипты как библиотеку операций. Обычные формы не доказаны.
Дублирует r13 (тот же набор скилов). Vanessa-скил — спецслучай C8 UI, не
проверка.

Предварительное решение: **адаптировать выбранные skills/скрипты**, не
подключать весь репозиторий. Конкурирует с r01; в Cursor можно взять
скрипты r12 как fallback edit, если Unica не подключается.

## Резюме для пользователя

Полезен для: правка XML метаданных и управляемых форм через DSL, выгрузка
ИБ, ленивые инструкции. Что не решает: обычные формы, граф BSL, компактный
индекс. Проверено: дерево скилов и тексты form-decompile/router.
Решение: частичный toolkit, не монолит.
