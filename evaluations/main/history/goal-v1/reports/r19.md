# r19 — https://github.com/fserg/mcp-1c-v1

Статус: обзор выполнен. Глубина: overview.

## Назначение и возможная роль

RAG-контур: обработка 1С выгружает markdown-структуру, loader → Qdrant,
MCP отвечает семантически. Роль: **семантический explore структуры**,
не граф BSL и не edit.

Канонический URL в статье — FSerg/mcp-1c-v1 (тот же автор, регистр).

## Заявления и подтверждения

- **c19-rag-stack** DOCUMENTATION. Qdrant + embeddings + MCP.
- **c19-epf-export** DOCUMENTATION. Нужна обработка в ИБ для выгрузки
  структуры — не работает «просто по папке XML» как r02/r15.
- **c19-forms** UNKNOWN. Выгрузка «структуры» не доказала обычные формы.
- **c19-dup** INFERENCE. Дублирует C1 хуже r02/r15: предварительная
  векторизация, Docker, нет callers.

## Оценка относительно цели

Авторский README r02 как раз противопоставляет RLM такому RAG. Для
критерия контекста и ежедневной работы с файловой выгрузкой r19 не
нужен. Спецслучай: «нечёткие вопросы по структуре», если кто-то уже
держит Qdrant.

Предварительное решение: **не включать в минимум**; спецслучай RAG.

## Резюме для пользователя

Полезен для: семантический поиск по дампу структуры. Что не решает:
навигация по коду, edit, ordinary forms. Решение: исключить.
