## Назначение и возможная роль

GitHub Action (TypeScript, node16): ставит в CI платформу 1С или EDT через
`oneget`. Роль: **провижининг CI-среды**, не локальный контур агента и не
C7 в смысле «агент собрал конфигурацию».

## Что изучено

Commit `350d87cd9033e2c8be280513151adfc3c3529c47`. `action.yml` (входы
`type=edt|onec`, версии), `src/index.ts` целиком: классы `OnecPlatform`
(скачивает/ставит, ищет `ibcmd`), `EDT` (`ring`, `1cedtcli`), `OneGet`.
README — **незаменённый шаблон** `actions/typescript-action`, не описывает
1С. Есть `__tests__/`, `dist/`.

- **c07-ci-install** SOURCE. `run()` ветвит edt/onec, качает oneget с

## Оценка относительно цели

Для ежедневной Windows-разработки в Cursor не нужен. Для CI-ветки
feedback loop — полезный кусок, если пользователь собирает в GitHub
Actions. Не дублирует r09 (r09 *использует* уже установленную платформу).

Предварительное решение: **спецслучай CI**; не в минимальный локальный набор.

## Резюме для пользователя

агентский цикл. Проверено: action.yml и index.ts; README вводит в заблуждение.
