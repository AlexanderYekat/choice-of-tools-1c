# r10 — https://github.com/alkoleft/mcp-bsl-platform-context

Статус: обзор выполнен. Глубина: overview.

## Назначение и возможная роль

Kotlin MCP `mcp-bsl-context`: поиск по синтакс-помощнику установленной
платформы. 5 tools: `search`, `info`, `getMember`, `getMembers`,
`getConstructors`. Роль: **готовый docs-адаптер** (C4) над установкой 1С.
Идеи чтения справки — от [bsl-context](https://github.com/1c-syntax/bsl-context).

## Оценка относительно цели

Закрывает C4 с малой поверхностью (5 tools, всё ещё многовато vs 1
`docs`). Не indep core: логика внутри JAR. Для минимального контура:
либо `unica.docs`, либо r10, либо CLI r04 за своим facade — не все сразу
(C14).

Предварительное решение: **основной готовый MCP-docs, если не берём
unica.docs**; иначе fallback. Не вместе с r18.
