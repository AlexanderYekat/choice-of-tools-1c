## Назначение и возможная роль

Плагин 1C:EDT, поднимающий MCP внутри IDE: семантика модели EDT,
валидация, отладка, edit метаданных и **управляемых** форм. Роль:
**семантика/debug только для EDT-проектов**. AGPL-3.0-or-later.

## Оценка относительно цели

Лучший найденный semantic/validate/debug **внутри EDT**. Для цели с
обязательными обычными формами и выгрузками конфигуратора — спецслучай,
не основа. Не ставить в минимум вместе с обещанием обычных форм.

Предварительное решение: **спецслучай EDT-проектов**.

## Резюме для пользователя

Полезен для: семантика и отладка в EDT, edit УФ через модель IDE.
Что не решает: обычные формы (явный отказ), работа без запущенного EDT.
Решение: отложить, кроме EDT-only команд.
