# r08 — https://github.com/ruslan-hut/onec-mcp

Статус: обзор выполнен. Глубина: overview.

## Назначение и возможная роль

Go MCP/HTTP-шлюз к *бизнес-данным* ERP (клиенты, остатки, продажи, ДЗ/КЗ)
через HTTP-сервисы 1С + OAuth. Роль: **runtime data access для аналитики**,
не разработка конфигурации.

## Что изучено

Commit `245de611ff2acc46e7b8f6a55e50a169645c8e90`. README (features, ~18
MCP tools, multi-tenant, admin UI), заявленная структура `internal/mcp`,
`internal/onec`. Код handlers не читался. LICENSE заявлена MIT.

## Заявления и подтверждения

- **c08-erp-tools** DOCUMENTATION. Таблица tools: resolve_* и отчёты sales/
  stock/money. Лимиты строк (max_rows 5000) — намёк на C9, но предмет не
  исходники.
- **c08-not-dev** INFERENCE. Нет BSL, метаданных, форм, сборки.

## Оценка относительно цели

По C1–C7, C13 бесполезен. Пересекается с r06 по доступу к ИБ, но для
другого пользователя (финансист/операционист). Включать в контур
разработчика — лишняя tool surface (C10, C14).

Предварительное решение: **исключить из сценария разработки**.
