Статус: обзор выполнен. Глубина: overview.

## Назначение и возможная роль

Python MCP + веб UI: семантический поиск по 2262+ шаблонам BSL (ChromaDB,
embeddings). 6 tools включая CRUD шаблонов. Роль: **рецепты кода**, не
справка платформы и не индекс конфигурации пользователя.

## Заявления и подтверждения

- **c14-six-tools** DOCUMENTATION. templatesearch, list/get/add/update/delete;
  list с offset/limit (C9 частично).
- **c14-heavy** DOCUMENTATION. Docker, Chroma, SentenceTransformer/OpenAI.
- **c14-not-project-code** INFERENCE. Ищет по корпусу шаблонов, не по
  рабочей конфигурации — не C1/C2.

## Оценка относительно цели

Добавляет tool surface и инфраструктуру ради примеров. C4 частично
пересекается (как писать код), но хуже точечной справки API. Для
минимального контура не нужен; спецслучай «подобрать типовой фрагмент».

Предварительное решение: **спецслучай / не в минимум**.

## Резюме для пользователя

Полезен для: поиск готовых сниппетов BSL. Что не решает: исследование
конфигурации. Решение: не включать по умолчанию.
