## Назначение и возможная роль

Сырой HTML-дамп документации платформы (`objects/`, `tables/`), без
README и без кода обработки. Роль: **корпус страниц**, не инструмент.

## Что изучено

Commit `95dc6864c205969bfd7b9f5cac663a5043b89a95`. Корень содержит только
два каталога. Файлы вида `Global context.html`, `catalog*.html`. Кода,
лицензии, индекса нет в listing.

## Заявления и подтверждения

- **c11-html-dump** SOURCE. Дерево — HTML-объекты, не сервис.
- **c11-no-api** SOURCE. Нет MCP/CLI/парсера.

## Оценка относительно цели

Хуже r04/r10 как источник для агента: страницы придётся индексировать
самим. Имеет смысл только если нужен офлайн-корпус без HBK.

Предварительное решение: **не включать**; корпус на крайний случай.
