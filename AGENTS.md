# Работа с исследовательским репозиторием

Этот файл — загрузчик: стабильные правила и указатели. Не память
исследования.

Сюда не записывать архитектурные решения, выбранные или отклонённые
продукты, критерии текущей цели, историю уточнений и пересказ файлов
запуска. Такие сведения живут в каталоге запуска и читаются по
необходимости. Менять `AGENTS.md` только если сменились каталог
текущего запуска, skill или правила ниже.

Текущий запуск: `evaluations/main/`. Сначала его `STATE.md` — там
порядок чтения, версия цели и следующий шаг. Обычное продолжение
не читает `history/` и `GOAL-CHANGE.md`: они нужны только чтобы
проверить происхождение решения, старый критерий или evidence.
Методика кандидатов:
[repo-evaluation](.agents/skills/repo-evaluation/SKILL.md)
(`references/methodology.md`, `references/formats.md`).

Новый запуск — только по явной просьбе, отдельно от шаблонов skill
и не поверх текущего каталога.

Выдержки и доказательства — в файлах запуска. Полные клоны кандидатов
не коммитить (`_sources/`, `source-checkouts/`).

Обвязка 1С — opt-in: маркер `v8stands.yaml`. Стенд `simple` смотрит на
выгрузку `source-checkouts/simple1CAiConf`. Бинарь `v8-runner` в репозиторий
не копировать. Не делать `init`/`load`/`build` информационной базы без
отдельной просьбы.

Не создавать commits, push, PR, удалённые репозитории, глобальные
установки и пользовательские настройки без отдельного задания.
